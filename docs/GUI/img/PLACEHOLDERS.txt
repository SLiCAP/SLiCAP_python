SCREENSHOTS STILL TO CAPTURE
============================

Drop the finished PNGs in docs/images/ under exactly these file names; the
manual and the README then pick them up with no further edits.

General rules
-------------
* Size the APPLICATION WINDOW to about 1600 x 1000 before capturing. A
  2560-px-wide capture is displayed by GitHub at ~900 px, which makes every
  label unreadable.
* Capture the window, not the whole desktop (no panels, no wallpaper).
* Use a project that looks like real work (Vamp / VampQspice), not an empty
  sheet: values filled in, a parameter table present, nothing marked "?".
* Light theme, default style, 100 % zoom unless a shot says otherwise.
