===============
Getting Started
===============

Requirements
============

* Python 3.12 or newer
* SLiCAP 5.1  or newer
* For LaTeX-typeset labels and figure export: ``pdflatex`` and ``dvisvgm``
  (a TeX distribution such as TeX Live, or MikTeX).  These are optional — without them the
  editor falls back to plain-text labels.
  
Launching the GUI
=================

With SLiCAP installed the GUI can be started by entering: 

>>> slicap

in a terminal. This brings up the *Structured Electronic Design Environment* shown below:
