=============
System design
=============

.. image:: ../API/img/colorCode.svg

From version 6.5 SLiCAP models and simulates systems at the level of their
functions: blocks driven by clocks, connected by signals, drawn as a system
diagram in the schematic editor. This part of the manual describes that
system-level design and analysis. It is being written.
